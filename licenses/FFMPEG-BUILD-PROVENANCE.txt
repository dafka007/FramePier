FramePier 0.2.3 - bundled FFmpeg: build provenance
==================================================

STATUS: recorded facts only. This file is NOT a statement of license compliance.

What is installed (tools\ next to FramePierHelper.exe)
------------------------------------------------------
ffmpeg.exe, ffprobe.exe and the shared libraries they load:
  avcodec-62.dll, avdevice-62.dll, avfilter-11.dll, avformat-62.dll,
  avutil-60.dll, swresample-6.dll, swscale-9.dll   (FFmpeg libraries)
  libmp3lame-0.dll                                  (LAME 3.100, MP3 encoder)
  libwinpthread-1.dll                               (mingw-w64 winpthreads)

The libraries are separate DLLs so that each one can be replaced by a
modified or newer build of the same library (FFmpeg: LGPL "relink" requirement
by way of dynamic linking). Replacing them is unsupported by FramePier.

-------

          1a748fe2cd43e3ead22fafb1b5b7d77f153898a8 (RELEASE file: 8.1.2)
          Built unmodified.
LAME    : lame-3.100.tar.gz
          https://download.videolan.org/pub/contrib/lame/lame-3.100.tar.gz
          SHA-256 ddfe36cab873794038ae2c1210557ad34857a4b6bdc515785d1da9e175b1da1e

          include/libmp3lame.sym (upstream LAME bug #503; the symbol is not in

          and the workflow copy for the exact command.
winpthreads : MSYS2 package mingw-w64-ucrt-x86_64-libwinpthread
          14.0.0.r426.g4564ee4b5-1 (mingw-w64 git 4564ee4b5063097bf747af3a3f8270a28adff820), permissive license.
          The shipped license text was checked byte-for-byte against that revision.

FFmpeg configuration (from "ffmpeg -buildconf" of the shipped ffmpeg.exe)
-------------------------------------------------------------------------
--prefix=/ucrt64 --enable-shared --disable-static --disable-autodetect
--enable-libmp3lame --enable-schannel --disable-doc --disable-debug
--disable-ffplay
No --enable-gpl, --enable-version3 or --enable-nonfree. "ffmpeg -L" of the
shipped build reports the GNU Lesser General Public License version 2.1 or later.
Other optional libraries are disabled (--disable-autodetect); schannel is the
Windows system TLS component and is not redistributed.

Build environment
-----------------
GitHub Actions windows-latest, MSYS2 UCRT64 via msys2/setup-msys2 (pinned commit
ec48f7c5447b3140e2b088413ae3a55687bccb6e). Full package list:
third-party/ffmpeg-shared/msys2-package-versions.txt. Compiler: mingw-w64-ucrt-x86_64-gcc 16.2.0-5.
The exact workflow: third-party/ffmpeg-shared/ffmpeg-shared-prototype.workflow.yml.txt.
Byte-identical rebuilds have not been demonstrated.
