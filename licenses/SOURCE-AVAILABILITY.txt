FramePier 0.2.3 - where the source for bundled components is published
=====================================================================

The FramePier installer is distributed from its GitHub releases page:
https://github.com/dafka007/FramePier/releases
The corresponding source for the GPL- and LGPL-licensed components is published as assets on that
same release page, next to the installer, and is available for as long as the installer is.
It can be downloaded from there without charge.
